## خدمة 1 — تطوير Backend و API بـ Java Spring Boot

**العنوان:** تطوير Backend وواجهات REST API باستخدام Java Spring Boot

**الوصف:**
أحتاج نظامًا خلفيًا موثوقًا؟ أبني لك Spring Boot API مع توثيق OpenAPI، مصادقة JWT، وقاعدة بيانات PostgreSQL، وتسليم Docker.

**يشمل:**
- تصميم النموذج والنطاق (Domain)
- REST API + توثيق
- مصادقة وصلاحيات
- Docker Compose للتشغيل المحلي
- ملاحظات قرارات تقنية مختصرة

**لا يشمل:** تصميم واجهة معقدة من الصفر، تطبيقات موبايل.

**مدة تقريبية:** 7–14 يوم حسب النطاق  
**سعر ابتدائي مقترح:** حسب باقة Khamsat (اربطها بحزمة API MVP من docs/brand/services-packages.md)

## خدمة 2 — أنظمة طوابير وأتمتة (RabbitMQ / Workers)

**العنوان:** بناء أنظمة طوابير وعمال خلفية لمعالجة المهام والحالات

**الوصف:**
تحويل المعالجة اليدوية أو البطيئة إلى مسار طوابير: استقبال حدث → قواعد توجيه → تعيين عادل → إعادة محاولة عند الفشل.

مناسب لـ: تذاكر الدعم، حالات تشغيلية، إشعارات، مهام خلفية.

**يشمل:**
- تصميم الطابور وإعادة المحاولة وDLQ
- لوحة مراقبة بسيطة + مقاييس
- تجربة تشغيل عبر Docker

**مرجع معرض الأعمال:** CaseFlow
