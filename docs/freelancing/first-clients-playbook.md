# First Clients Playbook

## Goal

Land the first paid milestone while employed, without burning out or violating employer IP/NDAs.

## Phase A — Minimum credible presence (after CaseFlow + site)

1. Portfolio URL live (even static hosting)  
2. CaseFlow demo link or GIF walkthrough  
3. Upwork profile filled with brand copy from `docs/brand/platform-profiles.md`  
4. 2–3 portfolio items attached (CaseFlow case study PDF/screenshots)

## Phase B — Platforms

| Platform | Role | Tactic |
|---|---|---|
| **Upwork** | Primary USD | Specialized profile; proposals with demo links; Connects spent only on niche matches |
| **Khamsat** | MENA / Arabic | Publish 1–2 services: API/backend, integrations/automations; respond fast in Arabic |
| **Freelancer** | Secondary | Selective bids; same proposal template |

## Phase C — First wins

1. Take a **$300–800** fixed milestone that maps to a known pattern (API + worker, provider adapter, routing rules).  
2. Over-communicate: daily note, demo video at end, decision log.  
3. Ask for a review immediately after delivery.  
4. Raise rates after 2–3 reviews.

## Red flags

- Client refuses a discovery call and wants full system for $50  
- Asks for employer source code or confidential AML/telecom details  
- Scope expands without amending the milestone  

## Compliance

- Never reuse employer proprietary code or datasets  
- Use only anonymized metrics publicly  
- Do not work on direct competitor products if your employment contract forbids it — check your contract  

## Measurement

Track weekly: proposals sent, interviews, milestones won, $ earned, hours spent.  
Optimize for **interview rate**, not proposal volume.
