# Personal Brand — Amr Samy

## Positioning statement

I build backend systems that turn slow, fragile business processes into fast, reliable pipelines — queues, rules, integrations, and APIs that hold up under real volume.

## USP

**Measurable throughput engineering.** Clients hire me for backends where latency, volume, and routing matter — backed by anonymized career outcomes (detection pipeline cut from ~45 minutes to ~2 minutes; campaign systems sending 20M+ messages), not generic “clean code” claims.

## Why a client should choose me

- Rare combination of **workflow/queue backends**, **high-volume outbound integrations**, and **cloud data services**.
- I design for **concurrency, failure modes, and fair routing** — not only CRUD endpoints.
- Portfolio demos show **live metrics, failure injection, and architecture decisions**, so buyers can verify how I think.

## Business problems I solve

- Batch or nightly jobs that take too long or fail under load
- Cases/alarms/tasks that need rule-based, fair assignment across agents
- Brittle integrations across REST, SOAP, SMS/email providers, and cloud storage
- “Add an AI feature” without rebuilding the whole product
- Need a solid Spring Boot API + workers, Dockerized, with clear monitoring

## Services

1. Spring Boot API / microservice design & build  
2. Background workers, queues (RabbitMQ), retry & DLQ design  
3. Integration adapters (REST/SOAP, storage, messaging providers)  
4. Performance optimization of batch/rule pipelines  
5. AI feature endpoints (generation + persistence + rate limits)  
6. Dockerized delivery + basic CI + observability hooks  

## Ideal client

SMB or mid-market product/ops teams that need backends processing lots of work reliably — campaigns, queues, cases/alarms, legacy API bridges, AI feature endpoints.

## Niche ranking (lead with these)

1. Backend + API development  
2. Business process automation / workflow + queues  
3. System integrations  
4. High-throughput / batch backends  
5. AI-powered backend features (feature, not “AI engineer” brand)  
6. Cloud-backed apps (deployment competence)
